# 语法多步学习路径

`GrammarLearningPathPlanner` 从当前语法目标沿 `prerequisite_for` 关系取传递闭包，按拓扑顺序列出全部前置节点和目标节点。它再从有学习记录的其他语法概念中，选一条长期薄弱点作为复习分支，连同该弱项的前置节点加入路径。当前作文目标始终排在复习分支之前；同一层中先处理掌握度较低、近期失败较多的节点。知识图谱若存在前置环，规划明确失败。

## 掌握度判断

路径中的每个节点有三种学习状态：`learn`（无证据或 BKT mastery 低于 0.40）、`verify`（尚未满足掌握门槛，需要独立验证）、`mastered`。未掌握前置节点会使依赖它的步骤显示为 `blocked`。第一个未被阻塞的 `learn` / `verify` 节点是下一步。

掌握门槛由 `PathMasteryRules` 集中定义，默认值尚未按真实教学数据校准：

- 从未掌握进入已掌握：BKT mastery ≥ 0.80、证据 confidence ≥ 0.50，并有至少两次低提示成功，或一次迁移练习成功。
- 已掌握状态可保留到 mastery < 0.65，避免边界附近来回切换。
- 近 30 天同知识点出现两次失败后退回待验证；此后须在最近一次失败之后重新取得两次低提示成功或一次迁移练习成功，才可再次进入已掌握。

`path_mastered` 保存在 `knowledge_states`，由 `StudentStateManager` 在学习证据写入事务中更新。现有记录在迁移后从保守的未掌握状态开始，后续证据可使其达标。`confidence` 是项目原有的证据数量函数，不是统计置信区间。低提示成功和迁移成功只代表目前工作流能够核验的有限行为，不能单独证明稳定掌握。

## 接入边界

Planner 在语法诊断后以当前作文中的错误为主目标；长期弱项作为复习分支。学习路径通过只读 Tool Runtime 返回给 Planner，随计划传给 Teaching Agent，并在语法工作区展示。路径规划器只决定知识点顺序；教学动作仍由 `PedagogyPolicy` 约束。每次请求重新读取 Student State 并规划，不把计划当作永久课程表。

当前八阶段写作流程仍按原有阶段门槛推进，尚未要求学生逐一完成路径中每个复习节点才能结束语法修改阶段。路径是可解释的教学规划与展示，不是独立的跨会话课程执行器。
