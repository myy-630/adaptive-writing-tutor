# 全流程演示记录（2026-10-26）

这是一条在本地浏览器、真实 DeepSeek 服务和 PostgreSQL 上完成的项目自编示例，不是公开 Benchmark 或教学效果实验。会话 ID：`f75036ad-2567-4f47-b28e-d2b7eb82fc34`。题目要求学生写一篇关于学校科学展的记叙文，覆盖项目、团队合作与结尾感受。

| 阶段 | 实际操作与可见结果 |
| --- | --- |
| 1 审题 | 建立八年级学生、题目和会话；填写对象、目的、文体、要点、时态、人称与限制。通过后进入初稿。 |
| 2 初稿 | 提交 86 词的示例作文，故意保留 `Last week, she go ...`。进入语法修改。 |
| 3 语法修改 | UI 定位 `go`，显示“时态 → 动词”知识路径与微课。先提交一次未修改的尝试，阶段保持不变且提示更具体；再将 `go` 改为 `went`，通过门槛。 |
| 4 结构修改 | 填写开头、主体、结尾结构图，并把事件重排为三段。 |
| 5 内容补充 | 填写观点、原因、例子、细节、感受，给修桥过程加入具体动作与对话；稿件为 111 词。 |
| 6 语言优化 | 说明问题→应对→结果的句间关系，明确 `middle` 的指代并调整结尾过渡；稿件为 114 词。 |
| 7 二次重写 | 辅助教学区隐藏；依据修改清单独立提交不同于 Draft 1 的 104 词 Draft 2，并勾选独立完成。 |
| 8 最终评估 | 生成 Draft 1 / Draft 2 的规则对比：识别到的时态问题消失 1 处、重复 0 处、新增 0 处；会话标记完成。刷新浏览器后仍恢复完成状态和 Draft 2。 |

数据库核对：该会话有 10 个工作流事件（其中 1 次语法未通过）、7 个保存的稿件版本、26 条 Tool Trace、9 条学习证据。Student State 的提示依赖统计含 9 条证据，时态知识节点有 2 条证据；能力分仍显示初始 50%，因为这次演示没有产生可用于能力 EMA 的量表分数，不能把阶段通过率伪装成能力评分。

工作流记录的 Policy 动作包括 `location_hint`、`socratic_question`、`break_down`、`self_check` 和 `independent_retry`；九个生成回复的在线 Pedagogy Evaluator 结果均为 `pass`。这条会话没有选择需要检索材料的动作，因此 26 条 Tool Trace 中没有 RAG 调用。为单独展示模块 4，另从 139 条本地资源索引以 `simple_past` 知识点过滤检索，实际返回一条项目演示迁移练习和一条项目演示语法讲解，结果记录 BM25、dense、RRF、元数据过滤和重排理由。`tense` 的严格 ID 过滤未命中资源，反映当前教学语料覆盖有限，不应描述成这条会话使用了 RAG。模块 10 的写作对比、Policy 消融和 MRBench 校准固定报告均成功冻结回放。

另创建了一个要求 `independent` Mode 的全新八年级示例会话。Planner 读取到该学生尚无能力或知识证据后，依规则改选 `guided`，随后 Policy 给出 `location_hint`、Teaching Agent 生成教学回复、Evaluator 判为 `pass`。这证明 Mode 由 Planner 决定，而非客户端的初始请求强制决定；不能把这个会话当作独立模式的现场演示。独立模式的无教学输出和 UI 权限由既有集成与前端测试覆盖。

演示时发现并修复两处阶段表达问题：语言优化时模型误称当前文本为“second draft”，现在由独立 Pedagogy Evaluator 的确定性检查拦截；进入最终评估后旧版模型曾要求再次写稿，但该阶段 UI 只允许 `finalize`，现在工作流直接进入等待评估的状态，不再生成多余教学指令。完成页面还会隐藏无效输入并把结果标为“学习反馈”。这些修复已通过后端 93 项和前端 29 项回归；既有已完成会话保留其历史事件，刷新后显示最终反馈。

这个对比只覆盖 Grammar Analyzer 当前能识别的规则，不能代表作文整体质量或学生长期学习效果。
